Chromosphere | MUON is installed.

FL STUDIO (20.8 or newer)
  1. Options > Manage plugins > "Find plugins" (tick "Verify plugins" the first time).
  2. Type  MUON  in the filter box; tick the star in the F column to add it to your favourites.
  3. Add it to a mixer insert slot: it is an effect, "Chromosphere | MUON".
  4. To drive the resonators from notes (Pitch: MIDI), route a MIDI Out channel to the plug-in.

OTHER DAWS
  Rescan VST3 plug-ins; MUON appears as an effect from "Chromosphere" (Dynamics / Distortion).

UPDATES
  MUON checks once a day for a new version (one small file from the release page). When one is out, the
  Updates button in the header lights up: click it, then "Install now". Turn on automatic install there to
  have new versions install silently when you close your DAW. Both can be switched off.

PRESETS
  Your own presets are saved in  %APPDATA%\ChromosphereMuon\Presets.

UNINSTALL
  Windows Settings > Apps > Chromosphere | MUON > Uninstall.

Windows may warn ("Windows protected your PC") because the installer is not code-signed:
More info > Run anyway.
